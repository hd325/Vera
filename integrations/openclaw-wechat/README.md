# Vera 微信接入源碼

本目錄保留 Vera 與本機 OpenClaw 微信通道的接入源碼，包括登入綁定、授權檢查、對話與文件工具橋接，以及持久發送佇列。網站核心功能不依賴此集成。

**預設關閉：** `ENABLE_WECHAT=false`。未啟用時不需要 Node.js、OpenClaw 或微信帳號。公開版不包含微信憑證、已綁定帳號、私人 profile、網關運行副本或歷史收發資料。

## 原型的版本約束

| 元件 | 源碼對應版本 |
| --- | --- |
| Node.js | `>=24.16.0 <25` 或 `>=26.1.0`，以本目錄 `package.json` 為準 |
| OpenClaw | `2026.11.3` |
| 騰訊微信插件 | `@tencent-weixin/openclaw-weixin@2.4.10` |
| 微信模型 | `config/wechat_model.py` 定義的華為雲 MaaS 配置 |

適配依賴固定版本的插件結構。版本或補丁錨點變化時應停止並重新檢查，不能僅升級套件後假定兼容。這些約束來自現有原型，不代表所有平台上的真實微信登入與收發均已驗證。

## 部署順序

1. 先完成 [網站核心安裝](../../README.md#快速開始)，建立自己的帳號並確認網站可用。
2. 自行安裝符合版本要求的 Node.js／npm，取得對應服務權限並配置自己的華為雲 MaaS 憑證。
3. 審閱並使用現有的 `scripts/setup_openclaw_wechat.py` 和三個適配腳本。主腳本可安裝固定版本、配置獨立 profile 和鏈接本目錄；它會寫入本機配置，不是網站核心安裝步驟。`--configure-only` 只更新配置，`--skip-core` 跳過 OpenClaw 核心安裝。不要在未核對現有 profile 時直接覆蓋自己的配置。
4. 自行完成網關與通道的配置，確認服務令牌和本機 broker 可用，再明確設定 `ENABLE_WECHAT=true` 並重啟網站。
5. 由已登入網站的本人主動發起微信連接、掃碼及最後確認，再驗證自己的實際收發流程。

這裡不提供一條指令即可完成全部網站、網關、平台授權和後台常駐的承諾。需要開機／登入後常駐時，由部署者另行選擇和核對服務管理方式；`--install-daemon` 會變更 OpenClaw 的服務設定，不是必需參數。

## 配置與隔離

- `ENABLE_WECHAT`：網站是否啟用此集成，預設 `false`。
- `HOUKONG_WECHAT_ENV_FILE`：顯式指定本次部署的私人 profile 環境檔案。
- `HOUKONG_WECHAT_SERVICE_TOKEN`：網站與本機 broker 之間的服務令牌，應由部署者生成並私下保存。
- `HOUKONG_WECHAT_BROKER_URL`：本機 broker 地址；現有原型使用 loopback `http://127.0.0.1:18790`。
- `example-account`：微信 profile 的模型密鑰引用；與網頁模型選項分開管理。

原型沿用 `houkong-wechat` profile／插件 ID，預設網關地址為 `127.0.0.1:18789`。保留這些協議標識是為了兼容，不影響產品名稱 Vera。部署者應使用自己的獨立 profile 和受限本機資料位置；不要把 `.env`、二維碼／登入憑證、帳號綁定資料、網關日誌或發送佇列提交到 Git。

## 現有資料流

預設流程由微信通道轉發到網站的聊天處理函數，使用微信獨立模型配置。文字回覆、進度與文件投遞經持久 outbox 處理；微信附件透過網站文件流程保存為該使用者的個人資料，不會自動發布到班級或全校。

`HOUKONG_WECHAT_NATIVE_GENERATION=1` 保留舊版原生生成分支，供適配排查使用；一般部署無需設定。網頁聊天選單不會改變微信分支的模型。

橋接工具使用服務端授權的帳號、綁定與回合資訊。模型工具參數不能指定任意使用者、文件路徑或接收人。發送前重新校驗綁定與投遞許可；狀態不確定時不應宣稱送達或自動重複發送。

## 驗證範圍

本次公開版只保留並檢查集成源碼及安裝邊界，未用真實微信帳號驗證登入、多帳號同時在線、文字／文件收發或外部平台部署。網站與合成測試的通過結果不能代替這些驗收。

完成部署後，應使用部署者自己的測試帳號確認綁定、解除綁定、暫停／恢復、重複事件及文件權限；平台或插件升級後重新驗證。倉庫未附帶舊內部驗證腳本或歷史回執，不應按不存在的命令執行測試。

公開版使用獨立的 `vera` OpenClaw profile。啟用前明確把 `HOUKONG_WECHAT_ENV_FILE` 指向自行建立的 `.openclaw-vera/.env`；未設定時不會讀取舊專案的 profile。
